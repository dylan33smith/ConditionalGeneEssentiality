Predicting conditional gene essentiality

Can a frozen protein-language-model embedding of a gene, plus a description of a growth condition's chemistry, predict when that gene becomes important? Across 48–62 bacteria/archaea and tens of millions of transposon-fitness measurements, the honest answer is subtle: the signal is real but local and memorization-dominated, and a simple nearest-neighbour lookup beats every global model we built.

The key result: why a lookup beats every model

The standard ML intuition — "a flexible model with rich features should beat a dumb lookup" — fails here for one specific, code-verifiable reason.

Framing update (2026-07-06): this "beat the kNN" contest is now understood to be a rigged benchmark (H1), not the scientific question. The numbers below are correct; their significance is re-scoped. See First-principles reframe for the corrected conclusion.

1 · The kNN uses information the model structurally cannot

chem-kNN code-verified

Reads gene g's own measured fitness at the training conditions chemically nearest to c, and averages them. A per-gene local regression using that gene's own answer key.

chemistry_knn_predict builds a gene×condition fit matrix and indexes g's row — harness.py:337.

global model

Takes (g's embedding, c's chemistry) → predicts, using weights shared across ~54,000 genes. At inference it never reads g's own labels.

It compressed g's history into shared weights during training and can't recover g's idiosyncrasies at test time.

The kNN is not a weaker competitor — it has strictly more relevant information at prediction time: the target gene's own phenotypic history.

2 · That own-history is the entire game here

  • The population signal is ≈0 within-gene. code artifact The gene-blind population profile (chem-NULL) scores 0.023 within-gene Spearman. Knowing which conditions hurt genes on average tells you almost nothing about which conditions hurt this gene.
  • A learned fitness-aware representation doesn't rescue it. code artifact linear-MF learns a free per-gene latent U[g] purely from fitness and still scores 0.429 < 0.485. The bottleneck is not representation quality; it's the global-vs-local structure.
A global model is a doctor predicting a never-seen patient from their demographic type. The kNN is a doctor holding that patient's own chart. When the patient's own history exists and is idiosyncratic — our exact setup — the second doctor wins.

First-principles reframe — the benchmark was rigged

A ground-up re-derivation (taking no prior conclusion at face value) that amends the framing of the whole warm-task program. The measurements stand; what they mean changes. Full version: research_log/SCIENTIFIC_SYNTHESIS.md §9.

1 · The one equation everything hangs on

Any single fitness measurement decomposes as:

fit(g,c) = μ + a_g + b_c + I(g,c) + noise
  • a_g — gene effect: how important gene g is on average (housekeeping genes are big here).
  • b_c — condition effect: how harsh condition c is on average.
  • I(g,c) — the interaction: is gene g specifically needed for condition c, beyond a_g and b_c? This is the biology.
  • noise — measurement error (the t-stat measures its size).

Ranking one gene's conditions fixes g (so a_g drops out) and eligibility selects genes where b_c is tiny — so the task is, purely, predicting I(g,c). That target was chosen by the metric + eligibility, not discovered. We were always trying to predict I(g,c) — that has not changed.

2 · Two hypotheses got conflated

H1 — a benchmark

"Can a learned model predict I(g,c) better than chem-kNN?" The kNN predicts I(g,c) by reading gene g's own measured I(g,c′) — its answer key — at other conditions.

This is the objective the project has been chasing.

H2 — the science

"Do the embedding (proxy for what g does) + chemistry (proxy for what c demands) actually contain generalizable I(g,c) signal, where nobody has the answer key?"

This is the original foundational bet — and the real prize.

3 · The warm contest is RIGGED three ways

The chem-kNN is handed: (a) the target gene's own labels at inference; (b) genes pre-selected (by eligibility) to have rich histories, where lookups thrive; (c) a random split that leaves each held-out condition a chemically-near measured neighbor. Given a high-rank, idiosyncratic target, a lossless lookup beating a lossy model is expected (Feldman long-tail) — a property of the formulation, not a verdict on deep learning.
The tell: R-COLD removes the crutch (no own-history) and the model wins vs chem-NULL. So H2 is a partial YES — the embedding carries real I(g,c) signal; it's only outgunned where memorization is available.

4 · What was never actually tested

Every failed model was global / compressing (MLP; linear-MF rank-32; naive retrieval-concat; global-MLP-predicts-residual). The family designed for this regime was never built (verified: no code): learned non-parametric (EASE / learned-metric kNN / TabR / canonical ResMem), a de-meaned target (model only I, not a_g/b_c), a denoised target.

The trap: a learned-local method that wins is a better memorizer — it confirms the memorization finding, it doesn't refute it. So this sweep is worth running only to make the H1 negative airtight, not as a path to a modeling "win."

5 · The 0.66 ceiling, corrected

Where it comes from: many conditions were run twice (replicates). Use replicate A's fitness as the "prediction" and replicate B's as the "truth" → NDCG@5 ≈ 0.66. That's how well the measurement predicts itself; no model can beat it, so ~0.34 of the error is pure noise.

The caveat: 0.66 is the ceiling of the single-noisy-measurement task — computed on the same noisy cells the model is graded on. Denoising raises it. The kNN→ceiling gap (0.175) is far bigger than the model→kNN gap (0.055), and is an unquantified mix of irreducible noise vs. structure the fixed kNN misses.

6 · Denoising — what it would look like

Every fit(g,c) is one noisy shot. The kNN reads single noisy neighbor values and inherits their noise; a model that denoises can average it out — so denoising is one of the few moves that could shift the balance, and it was never applied to the target.

  • Replicate-average — average repeated (gene, condition) measurements; the ceiling rises.
  • Precision-shrink by t — pull low-confidence cells toward the gene/condition mean (empirical Bayes).
  • Low-rank denoise — the matrix is ~ low-rank (few stress programs) + sparse; fit the low-rank part as a denoised target.

7 · A non-rigged benchmark

Demote chem-kNN from "the gate you must beat" to "a reference for what pure memorization achieves on warm data." The honest benchmark removes the near-neighbor gift so every method must generalize:
  • Primary split → leave-compound-out (scaffold / leave-chemical-class-out), plus cold-gene.
  • Bar → chem-NULL (population profile); scored as fraction of the (denoised) ceiling.
  • This measures H2 — is the biology in our features — instead of H1's rigged contest.

8 · Other ways to formulate the question

MoA = Mechanism of Action — for a drug, how it harms the cell (which target/pathway it hits; e.g. a β-lactam blocks cell-wall synthesis). Deconvolving MoA = inferring an unknown compound's mechanism from its genome-wide fitness fingerprint.

9 · The corrected conclusion

"No model beats the kNN" is re-scoped to: "no global model beats a lookup that's been handed the gene's own answer key, on a task selected to reward that." Expected, low-significance, and not the scientific question. Retire H1. The live science is H2 on honest splits and the reframed questions above — now materially strengthened by the new 62-org dataset (M. tuberculosis + a TB-drug panel; in-vivo mouse / in planta conditions).

1 · Cross-organism fitness regression (T-regime)T-regime ledger#
Hypothesis: Predict held-out organisms' gene×condition fitness from embedding+chemistry.
▶

Hypothesis / reasoning

Foundational bet: a frozen, proteome-contextualized, sequence-derived protein embedding (ProteomeLM) combined with a media-chemistry encoding contains enough information to predict conditional gene essentiality, and this generalizes across organisms. Concretely for this experiment: train pointwise MSE/MAE regression on fitness for a pool of organisms, hold entire genomes out, and predict held-out organisms' gene x condition fitness — expecting both good error metrics AND a biologically meaningful within-gene ordering of conditions.

How we tested this

DATA. Tn-seq gene-fitness measurements across a large multi-organism bacterial/archaeal panel (48 organisms were re-encoded in T5; the training split drew from the full org pool). Each row is one (gene, experimental condition) pair with a continuous fitness score. Inputs per row: a frozen ProteomeLM-L layer-8 gene embedding (1152-dim, mean-pooled, sequence-derived, proteome-contextualized, never fine-tuned) concatenated with a media-chemistry encoding of the condition.

SPLIT (the key design). Cross-ORGANISM holdout, i.e. leave-genomes-out: the canonical split protocol was multi_org_balanced (locked in data_contract/splits/locked_protocol.yaml). Whole organisms were held out for validation so that held-out orgs are NOT in train (leakage/split-overlap guardrails explicitly passed "by construction" in T1-DEC-001). The reported per-organism validation set covered 4 val organisms (ANA3, BFirm, pseudo3_N2E3, SyringaeB728a_mexBdelta in the T1 breakdown). All preprocessing (chemistry vocab, scalers, eligibility thresholds) was fit on train rows only; unseen val categories mapped to explicit <UNK>. Feature contract frozen at artifact de21504134c84a6c.

OBJECTIVE / WHAT WAS RUN. Pointwise regression on the raw continuous fitness score. The pre-registered co-primary metrics were RMSE and MAE (S2-locked thresholds RMSE=0.0212, MAE=0.005). The loss was mean squared error (MSE); T4-A explicitly tested Huber (delta 0.5/1.0/1.5) vs MSE and T4-B tested per-experiment z-scored targets vs raw — MSE + raw targets were retained. Model families swept across tiers: a shallow concat-linear MLP (T1, hidden 256), a 2-layer ResidualMLP (hidden 512, T3), plus encoder/layer/embedding ablations (T5). Training config throughout: 3 seeds {0,1,2}, 8 epochs, constant lr=1e-3, weight_decay=1e-4, batch_size=8192; cross-seed std reported; seed-0 bootstrap CIs (1000 row-resamples).

BASELINES / CONTROLS in the T-regime. The learned models were required to beat the locked S2 best-non-global baseline (embedding-NN, RMSE 0.5884 on multi_org_balanced) — which they did by ~0.07 RMSE. Ablation controls established the embedding was not the fixable lever: T5-B (PLM layer 0/4/8/12/18) and T5-C (ProteomeLM layer-8 vs raw ESM-C 600M) — ProteomeLM beat raw ESM-C by only ~0.006 RMSE.

THE DIAGNOSTIC THAT MATTERED. Beyond the co-primary RMSE/MAE, the project computed the biologically meaningful quantity: the within-GENE ranking of a gene's conditions (within-gene Spearman), compared against a replicate noise floor (~0.43 Spearman, the agreement between biological replicates = achievable ceiling). This is what exposed the failure. A supporting mechanism-check (run later, in the R-regime) confirmed the population/cross-gene condition profile carries essentially no within-gene signal: the chem-NULL baseline (predict the population condition profile, no gene specificity) scores ~0 within-gene Spearman. The homology cause was quantified in S1 (H-HOMO-01, 1.6 sigma: held-out-org genes far from any train gene in embedding space), and T1 reported a homology-bin RMSE breakdown (val rows binned by cosine to nearest train gene) confirming error grows with homology distance (RMSE ~0.40 at cosine <0.5 rising to ~0.55 at cosine >0.85).

Analysis — why it came out this way

The failure has a precise mechanism, stated in synthesis §1. Pointwise RMSE/MAE is dominated by each gene's baseline fitness level (the "gene-mean"). A regression model can score decent RMSE by fitting (a) gene means and (b) the population condition effect — which conditions hurt MOST genes — while learning NOTHING about the gene x condition interaction, which is the actual biological signal ("which conditions stress THIS gene"). The project later confirmed the population effect is worthless for ranking: the chem-NULL baseline (population condition profile, gene-identity-free) scores ~0 within-gene Spearman. So optimizing MSE/MAE across ~54k rows optimizes the wrong quantity for the ranking objective.

Two reasons are specific to the cross-ORGANISM setting: (1) Homology distance (S1 diagnostic, H-HOMO-01 at 1.6 sigma): a held-out organism's genes lie far from any training gene in ProteomeLM embedding space, so the model has no nearby anchor to place them. (2) Fitness-blindness of the embedding: ProteomeLM encodes sequence/structure/proteome-context, not how a gene responds to stressors; cross-org compounds this with distribution shift. Evidence for (2): ProteomeLM beat raw ESM-C by only ~0.006 RMSE (T5-C), so even the proteome-contextual machinery added almost no conditional signal.

The T1/T4/T5 ledger entries corroborate the "RMSE was fine but sub-threshold and metric-conflicted" picture: across the entire T1-T5 sweep every arm sat at RMSE ~0.50-0.52 with sub-threshold gaps, MSE and Huber conflicted on RMSE vs MAE, and only one intervention (T5-A adapter dim-reduction) produced any statistically robust gain — and it was still 20% of the RMSE threshold. None of this moved the within-gene ranking, which is why the project pivoted to the R-regime (within-organism, ranking metric).

What it means for the project

This is the pivotal negative that reframed the entire project. It cleanly separated two problems that RMSE conflates: predicting the LEVEL of fitness (easy, gene-mean-dominated, achieved) versus predicting the within-gene conditional ORDERING (the real, hard, biologically useful problem). Cross-organism transfer of the ordering is ~0 — frozen protein embeddings carry no transferable conditional-response information across genomes, for two reasons (homology distance + a fitness-blind embedding). The consequences: (1) the generalization claim was narrowed from cross-organism to WITHIN-organism (predict a known organism's genes under novel condition combinations); (2) the primary metric was changed from RMSE to per-gene ranking (within-gene Spearman + NDCG@k), the quantity a biologist actually uses. Everything in the later R-regime — the chem-kNN strong baseline, the memorization-dominated finding, the cold-gene diagnostic — descends from this result. It also set the durable lesson that a low RMSE can entirely hide a useless model when the target is heavy-tailed and gene-mean-dominated.

2 · The within-organism test harness (split · eligibility · metric · baselines · gate)R-LOCK artifact code#
Hypothesis: How every within-organism experiment is tested: the split, eligibility, baselines, and the gate.
▶

Hypothesis / reasoning

A single locked within-organism test harness — a cold-condition holdout split, a spread-based eligibility filter, a retrieval-first metric with hierarchical confidence intervals, three matched baselines, and a replicate ceiling — is a valid and sufficient lens to judge whether ANY learned model earns promotion for the "find a gene's top stressor conditions" task. Concretely: hold out 20% of each organism's conditions (which are chemically disjoint from train, so the task is genuine composition not recall); score only genes that vary enough to be rankable (tail_g over a per-org noise-scaled threshold); score the model and every baseline on the identical eligible val genes; and promote only if the model beats the chem-kNN gate by an effect-size margin with disjoint org→gene bootstrap CIs.

How we tested this

This is the shared test harness every within-organism ranking experiment runs through, defined across four locked decisions (R-LOCK-1 through R-LOCK-4, 2026-05-24 to 2026-05-25) and implemented in src/ranking/eval/harness.py. WHAT DATA: Tn-seq fitness values ("fit") for genes across growth conditions, per organism; a condition is keyed as condition_key = (expDesc, media, temperature). Population characterization spanned 48 organisms, 182,447 (org, gene) pairs, ~7,500 experiment assays, ~4,200 distinct conditions; the reliable-replicate headline subset is 23 orgs. THE SPLIT (R-LOCK-2): within each organism, hold out 20% of the DISTINCT conditions (fraction-based because org sizes span 17x), seed 0, with floor 3 / cap 30 held-out conditions per org. Holdout is at the CONDITION level, not the assay (expName) level — every replicate assay of a held-out condition goes to val together (hold_out_together) so no replicate of a val condition leaks into train. Held out at the condition level, val conditions turn out to be 100% chemically disjoint from train ("cold columns"; verified 0/78 overlap), so the model must COMPOSE gene embedding x condition chemistry rather than recall the exact condition — this is the deployment-relevant "novel conditions within a known organism" claim. Splits are stratified by expGroup where feasible; seeds 0/1/2 for multi-seed checks; Keio is the dev subset. THE ELIGIBILITY FILTER (R-LOCK-1): only rank genes that actually vary across conditions. Spread is measured as tail_g = p95 - p5 of a gene's fit across its conditions (NOT IQR — a gene essential in only 3-5 of 100 conditions has IQR ~ 0 yet is the single most rankable gene, so IQR would discard exactly the best targets). A gene is eligible if tail_g exceeds a PER-ORG threshold tail_min_org = max(0.20, 0.80 x (1 - r_replicate_org)), where r_replicate_org is that org's replicate reproducibility — noisier orgs (which span 5.4x, replicate Spearman 0.16 to 0.89) demand a higher spread bar. Val is HARD-filtered on this (m_min_val = 5 conditions; Spearman is undefined on constant fit). Train genes are all kept but WEIGHTED by w_g = clip((tail_g - tail_min_org)/(p75_org - tail_min_org),0,1) x min(m_g/m_min,1), so low-spread genes contribute little but still anchor the "predict near-flat for non-conditional genes" variance prior. DENOMINATOR PARITY: the model and every baseline are scored on the IDENTICAL eligible val gene set (min 5 conditions/gene, non-constant). THE THREE BASELINES (all in harness.py, split-specific for the cold-column primary split): (1) chem-NULL = chemistry_nearest_condition_profile — for a held-out condition c, find its chemically-nearest TRAIN condition c' by cosine distance on condition features and predict every gene's fit at c as the train-gene MEAN fit at c'; gene-blind population profile, the floor a real model must clear. (2) chem-kNN = chemistry_knn_predict (k=5) — predict gene g's fit at cold condition c from g's OWN train fit at its k chemically-nearest train conditions; it uses the gene's warm history bridged by chemistry and is the competitive gate. (3) linear inductive-MF = inductive_mf_predict — a bilinear model Fit[g,c] = U[g]·(W·x[c]) + b[g] with free per-gene latents U (genes are warm), a chemistry-feature column map W·x[c] that places COLD conditions via their features, and per-gene bias b, trained by (w_g-weighted) MSE; isolates whether the deep model's nonlinearity beats a linear feature-MF. THE REPLICATE NOISE FLOOR / ORACLE (R-LOCK-4, retrieval_noise_floor in harness): for each gene with >=2 replicate assays at >=5 conditions, use replicate A's fit as the PREDICTION and replicate B's fit as the TRUTH and compute NDCG@k/precision@k — the best any model could do given biological noise; reported as a ceiling line (only for the 23 orgs with adequate replicate design). METRICS (R-LOCK-4 v2): PRIMARY is NDCG@5 (retrieval; relevance = max(0,-fit) so a stronger stressor = more negative fit = higher gain, ranking conditions by predicted-most-essential first); SECONDARY/anti-gaming is within-gene Spearman and Kendall (full-list completeness). Every metric carries a HIERARCHICAL bootstrap CI: resample organisms with replacement, then genes within each chosen org (n=1000, 95% percentile) — because genes within an org are correlated, a flat bootstrap would be overconfident. THE GATE: a learned model is promoted over chem-kNN only if it beats chem-kNN by the effect-size margin (CLAUDE.md: >= ~0.026 NDCG@5) AND the two hierarchical-bootstrap CIs are DISJOINT; the harness also provides a one-sided hierarchical bootstrap p-value on the per-gene paired delta and Benjamini-Hochberg FDR across a tier's arms. WHAT WAS ACTUALLY RUN through this harness: the locked pointwise_huber model vs all three baselines, on both a fast 3-org gate (Keio+Caulo+MR1, seed 0, N=9,152 eligible val genes) and the 23-org / 3-seed headline (N=39,356 eligible val genes), pinned in the committed artifact data_contract/ranking/reval_baseline.json.

Analysis — why it came out this way

The harness works because it forces an apples-to-apples comparison on a deliberately hard task. The split makes val conditions 100% chemically-disjoint from train ("cold columns"): the model never sees the held-out condition during training, so it can only score well by composing the gene embedding with the condition's chemistry — the deployment-relevant claim ("novel condition combinations within a known organism"). The eligibility filter (tail_g = p95 - p5 of a gene's fit across conditions, over a per-org threshold scaled to that org's replicate noise) removes flat, non-conditional genes whose ranking is meaningless/undefined, and it uses tail rather than IQR specifically because a gene essential in only 3-5 of 100 conditions has IQR ~ 0 by construction yet is exactly the most rankable target. Denominator parity — model and every baseline scored on the identical eligible val genes — is what makes the deltas trustworthy. The three baselines triangulate what "learning" would even mean: chem-NULL (gene-blind population profile via nearest-chemistry train-condition mean) is the floor a real model must clear; chem-kNN (the gene's OWN warm history retrieved through chemistry) is the hard, non-parametric bar that turns out to WIN — because the split is transductive over genes, so simply looking up a gene's past behavior beats parametric generalization; linear inductive-MF (free per-gene latents + a chemistry-feature column map, Fit[g,c]=U[g]·(W·x[c])+b[g]) is the bilinear control that isolates whether the deep model's nonlinearity buys anything. The replicate oracle (replicate A predicting replicate B) sets the attainable ceiling. The gate (beat chem-kNN by the effect-size-anchored margin with disjoint hierarchical org->gene bootstrap CIs) is deliberately strict: the hierarchical bootstrap widens the CI to respect that genes within an org are correlated, preventing overconfident "disjoint CI" promotions. Analysis — why it came out this way

The sweep isolated the chemistry encoder while holding architecture (T5-A) and loss (pointwise MSE) fixed. Two clean findings emerged. The bottleneck is the fusion topology and the loss, not the chemistry features. R1 was therefore confounded (it varied the encoder while holding two suspect factors fixed), so the encoder verdict was recorded as provisional.

What it means for the project

This result set the strategic direction for the whole R-regime. The decisive read — that a deep model under pointwise MSE cannot beat a gene-specific similarity lookup — redirected effort toward fusion topology and ranking loss as the real candidate levers, and foreshadowed the eventual understanding of the "chem-kNN beats global learning" wall as a memorization regime rather than a fixable modeling gap.

Analysis — why it came out this way

Both a tiny bilinear model and a large nonlinear one plateau at the same place (~0.43 NDCG@5) and both lose to a simple local lookup (chem-kNN, 0.485). The synthesis pins the mechanism: the useful conditional-essentiality signal is gene-idiosyncratic and LOCAL — it lives in each gene's OWN deviations from the population/bulk condition profile (which itself carries ~0 within-gene signal, per chem-NULL). Any GLOBAL parametric model, regardless of size, minimizes average error over ~54k genes and therefore averages those per-gene idiosyncratic deviations away — they look like cross-gene noise to a shared parameter set. So the linear-MF (13k params, bilinear) and the deep model (2.5M params, nonlinear) converge to the same ceiling: the limiting factor is not the model's expressive power but the global-vs-local structure of the task. 'Capacity buys nothing' means: once you have enough parameters to capture the bulk pattern, adding ~190x more parameters and nonlinearity does not recover the gene-specific signal, because that signal is not learnable by any global function — it must be retrieved from each gene's own history (what kNN does). The linear-MF arm carries a second, sharper meaning (synthesis section 5): its free per-gene latent U[g] is a fitness-AWARE representation learned from scratch on the fitness data, discarding ProteomeLM entirely. That it still ties the frozen-embedding deep model and still loses to kNN shows the warm-task bottleneck is NOT the embedding's fitness-blindness — it is the global-vs-local structure. Even a perfect fitness-aware gene vector, used globally, loses to local lookup.

What it means for the project

This is the third independent leg (with encoder/R1 and objective/R-LOSS) of the project's central negative: on the within-organism warm ranking task, a learned GLOBAL model does not beat a simple local chemistry-similarity lookup — and here the specific lever ruled out is model capacity/nonlinearity. 'Capacity buys nothing' is not a tuning complaint; it is structural evidence that the bottleneck is the global-vs-local nature of the task, not model expressiveness. This directly de-risks and de-prioritizes scaling up the network. It also carries the project's sharpest strategic implication (synthesis section 5): because linear-MF's free latent U[g] is itself a fitness-AWARE representation learned from the fitness data, and it still ties the frozen-embedding deep model and still loses to kNN, the warm-task bottleneck is NOT the embedding's fitness-blindness. 5 · Loss family (R-LOSS)R-LOSS ledger#
Hypothesis: Does a ranking-aware loss (matching the metric) beat pointwise and the lookup?
▶

Hypothesis / reasoning

H-R-LOSS-01: that the training OBJECTIVE is the bottleneck — that swapping pointwise MSE regression for a ranking loss (pairwise RankNet/LambdaRank or listwise ListMLE/ApproxNDCG, including losses that optimize NDCG directly) would close the gap to the chem-kNN gate (NDCG@5 0.485). The motivation came from R1: since the encoder didn't matter and a linear matrix-factorization matched the deep model, the objective (using MSE to hit a ranking metric) was the suspected lever. The prediction: a ranking loss should beat pointwise MSE and approach or exceed the gate; if it doesn't, the bottleneck lies elsewhere (the local-vs-global nature of the signal).

How we tested this

DATA AND TASK: The within-organism top-k ranking task — for each gene, rank that gene's conditions to surface its top stressors, scored primarily by NDCG@5 (agreement on the top of the ranked list). Inputs are frozen ProteomeLM gene embeddings plus media-chemistry features; the target is Tn-seq fitness. SPLIT: A single fixed data split (R-LOCK-2 split seed 0) was used throughout; every model and baseline was scored on the identical common eligible validation gene set (denominator parity — a hard project rule). SCOPE: 23 replicate organisms (ANA3, BFirm, Btheta, Burk376, Caulo, Cola, Cup4G11, Dda3937, Ddia6719, DdiaME23, Dino, DvH, Dyella79, HerbieS, Kang, Keio, Korea, Koxy, MR1, Marino, Methanococcus_JJ, Methanococcus_S2, Miya). WHAT WAS VARIED: exactly one thing — the training loss. Six losses were compared: two pointwise (pointwise_mse, the R1 control; and pointwise_huber, a robustness control), two pairwise (pairwise_ranknet; lambdarank, which is NDCG-weighted pairwise and targets NDCG directly), and two listwise (listmle, a listwise permutation loss; approxndcg, a smooth NDCG surrogate that also targets NDCG directly). HELD CONSTANT: the encoder (multihot_425) and the architecture (T5-A, i.e. the AdapterResidualMLP), both pinned from R1-DEC-001, so any difference is attributable to the objective alone. BATCHING (a required methodological detail): pointwise losses were trained ROW-batched (their natural/best form, matching the R1 control), while pairwise and listwise losses were trained GENE-batched (required so a full per-gene list is present to compute pairwise/listwise terms). SEEDS/EPOCHS: each loss was run with 3 model seeds (0,1,2) for 15 epochs; reported per-loss numbers are mean +/- sd over the 3 seeds. BASELINES on the same eligible val genes: chem-kNN (the non-parametric local chemistry-k-nearest-neighbor gate to beat, NDCG@5 0.485), linear-MF (a linear matrix-factorization capacity reference from R1), chem-NULL (a chemistry-only null lower bound), and noise-floor (a replicate-agreement ceiling). PROMOTION RULE (pre-registered): a loss had to beat the chem-kNN gate on NDCG@5 AND achieve a Spearman gain of at least 0.023, with BH-FDR multiple-testing correction across the losses. The primary metrics were NDCG@5 and within-gene Spearman.

LambdaRank's NDCG@5 (0.431, 2nd best) with a collapsed Spearman (0.080) is diagnostic: a purely top-focused objective can raise top-of-list agreement slightly while wrecking full-list order, but it still cannot cross the gate. Concrete consequences recorded in the decision: (1) do NOT pursue fancier NDCG surrogates like NeuralNDCG/differentiable-sorting — LambdaRank already optimizes NDCG directly and lost, so the ~0.05 gap is about locality, not the loss surrogate; (2) DEMOTE R2 (fusion topology), since it is another capacity lever and thus low expected value; (3) PIVOT to a local/hybrid approach (explicit parametric+chem-kNN residual, retrieval/attention over chemically-near train conditions, or local refinement) — proposed as the next tier R-HYBRID; (4) carry pointwise_huber + multihot forward as the parametric base. The one durable positive: Huber is adopted as the default pointwise loss over MSE.

Hypothesis: Does truncating the loss to the top-5 (exactly the metric) close the gap?
▶

Hypothesis / reasoning

H-R-TOPK-01: The prior loss-family experiment (R-LOSS) rejected the ranking losses, but its ApproxNDCG/LambdaRank objectives optimized NDCG over the WHOLE ranked list. 7 · Static model+kNN ensemble (R-HYBRID-A)R-HYBRID-A ledger#
Hypothesis: Do the model and kNN carry complementary signal a static blend can exploit?
▶

Hypothesis / reasoning

H-R-HYBRID-01: the global parametric model (the frozen-embedding + chemistry MLP) carries signal that is COMPLEMENTARY to the local chem-kNN lookup, so combining the two should beat chem-kNN alone. This is the first test of whether the learned model adds ANYTHING on top of the local lookup — because no standalone global model (from R1 or R-LOSS) had ever beaten chem-kNN by itself. The answer decides whether the project has a genuine model contribution (path: keep hybridizing) or is purely memorization (path: characterization paper).

How we tested this

Data and split: The within-organism warm ranking task on the 23 replicate organisms (the headline subset with a reliable replicate noise floor), evaluated on 53,189 eligible validation genes. The task is "rank a gene's conditions to find its top stressors." Two predictors were fused: (1) the standalone global model — a Huber-loss, row-batched MLP over frozen ProteomeLM gene embeddings plus multihot media-chemistry features, which was the R-LOSS loss-family winner; and (2) chem-kNN, the local lookup baseline that is the project's promotion gate. Fusion method: a per-gene z-scored convex combination — for each gene, both the kNN scores and the model scores are z-scored (standardized) within that gene, then blended as alpha*z(kNN) + (1-alpha)*z(model). alpha was swept over [0,1], where alpha=1 is pure kNN and alpha=0 is pure model. First, the full-val alpha-curve was computed over all 53,189 eligible val genes (alpha in {0.0, 0.5, 0.7, 0.8, 0.9, 1.0}), which located the curve peak at alpha≈0.8. Because reading the peak off the same val set it is scored on would leak (curve-peeking), an HONEST held-out alpha-selection was then done: the val GENES were split 50/50 by hash into a tune half and a test half; alpha* was chosen to maximize NDCG@5 on the tune half only, then that fixed alpha* (=0.8) was applied and reported on the held-out test half — so the reported hybrid number is out-of-sample, not curve-peeked. Baselines/comparators: the hybrid was compared against pure chem-kNN (the gate) on the identical eligible val genes; a knn+linear-MF convex combo was also run as a reference fusion to check whether the deep model's complement exceeds linear matrix-factorization's. Primary metric NDCG@5 (top-of-list ranking agreement), with within-gene Spearman reported as the secondary full-list metric. Promotion requires clearing the pre-registered delta of roughly +0.023 to +0.026 NDCG@5 over the gate.

▶

Hypothesis / reasoning

H-R-HYBRID-01 (round 2): a LEARNED hybrid of the global parametric model (AdapterResidualMLP) plus the local chem-kNN lookup can extract MORE of the complementary signal than R-HYBRID-A's static z-score ensemble (which gained only +0.008 NDCG@5), ideally clearing the promotion delta (~0.026 NDCG@5 / ~0.023 Spearman over the chem-kNN gate). How we tested this

DATA & SPLIT: The warm within-organism ranking task on the project's canonical Tn-seq fitness data, restricted to the 23 replicate organisms that have a reliable replicate noise floor (the headline eval subset; eligibility_policy.yaml r_replicate_org). Genes are split transductively; evaluation is on the eligible val gene set with the eligibility filter r_lock_1_v1. Sample size: ~52,900-53,200 common eligible val genes shared across models (denominator parity). WHAT WAS ACTUALLY RUN: Three separate LEARNED fusions of the standalone parametric model (AdapterResidualMLP — the T5-A locked model, trained row-batched with weighted-Huber, the R-LOSS winner) with the local chem-kNN gate (k=5, cosine similarity on condition multihot; standalone NDCG@5 ~0.485 / Spearman ~0.24 on full val). 9 · Train-organism augmentation (R-AUG)R-AUG ledger#
Hypothesis: Does training on all 48 organisms narrow the gap?
▶

Hypothesis / reasoning

H-R-AUG-01: because the headline trains the global model on only the 23 replicate organisms (leaving ~25 embedded feba organisms, including some of the largest, out of training entirely), training the shared encoder on ALL 48 embedded organisms — while evaluating on the same locked 23 organisms against the same chem-kNN gate — should NARROW the model-to-gate gap, since more organisms give the encoder more (protein-embedding, chemistry)->fitness examples to generalize from. This is the cleanest, cheapest test of whether the model-to-gate gap is a training-data-VOLUME problem (fixable with more data, including external Tn-seq datasets) or a STRUCTURAL one (no transferable cross-organism signal).

How we tested this

Data and objective: the project predicts conditional gene essentiality and the active metric is within-organism top-k ranking of a gene's conditions ("find the top stressors for this gene"), scored primarily by NDCG@5 (k=5). The experiment asks whether adding more TRAINING organisms narrows the gap between the learned global model and the chem-kNN baseline (the promotion gate). The headline configuration trains AND evaluates the global model on only the 23 replicate organisms (ANA3, BFirm, Btheta, Burk376, Caulo, Cola, Cup4G11, Dda3937, Ddia6719, DdiaME23, Dino, DvH, Dyella79, HerbieS, Kang, Keio, Korea, Koxy, MR1, Marino, Methanococcus_JJ, Methanococcus_S2, Miya), leaving the other ~25 embedded feba organisms (including some of the largest: Putida, psRCH2, the pseudo* set, WCS417, Phaeo, Pedo557) contributing zero training rows.

Design (a clean controlled A/B): the same locked model architecture (pointwise_huber loss + multihot_425 chemistry features + T5-A encoder/adapter) was trained TWICE on the IDENTICAL locked evaluation. Arm 1 (base_23org): model trained on the 23 eval organisms only. Arm 2 (aug_48org): model trained on all 48 embedded organisms — the 23 eval organisms plus the 25 extra organisms (config extra_orgs=auto = all embedded organisms minus eval_orgs). Both arms were scored on the identical eligible validation gene set against the identical chem-kNN gate. Settings: 3 model seeds [0,1,2], split_seed=0, 8 epochs.

What was held fixed (the key control): the validation set, R-LOCK-1 gene eligibility, and ALL baselines (chem-kNN gate, chem-NULL, linear-MF) were produced exactly as prepare_r1_data over the 23 eval organisms. The extra 25 organisms contribute ENTIRELY to training and never touch the evaluation. This was implemented via R1Data.baseline_train (baselines score on the locked eval-organism train set) plus prepare_r_aug_data (grafts the extra-organism rows onto the .train split only, and extends the embedding/multihot matrices to the 48-organism union). Crucially, the chem-kNN gate was asserted bit-identical between the two arms (drift = 0.000000), which proves the evaluation is held fixed and only the model's training data changed. This is the one lever that can help ONLY the global model, because chem-kNN is per-organism-local and gains nothing from extra training organisms.

Baselines compared: the chem-kNN gate (primary promotion gate), plus chem-NULL and linear-MF, all scored on the same eligible val genes as the model. Primary metrics: NDCG@5 and within-gene Spearman (prec@5 also reported). Pre-registered promotion rule: augmentation must IMPROVE the model toward the gate (delta-NDCG@5 > 0 vs base, consistent across seeds) to justify ingesting more (including external) organisms. 12 · Dark-genome residual miner spike (R-DARK)R-DARK ledger#
Hypothesis: Are unannotated 'dark' genes enriched for surprising, chemically-specific essentiality?
▶

Hypothesis / reasoning

Because the project is memorization-capped (chem-kNN beats every learned model at predicting fitness), the proposal flips the question: instead of predicting fitness, treat chem-kNN as a null model of what is chemically predictable and mine its RESIDUAL — the conditional essentiality the lookup cannot explain. The specific hypothesis under test is that unannotated ("dark genome") genes — protein-coding genes with no/hypothetical/DUF/uncharacterized descriptions — are ENRICHED for reproducible, chemically-surprising essentiality (large studentized residuals) relative to annotated genes, so the dark genome is where the surprising conditional biology hides. This is a discovery task, not a ranking task, so NDCG@5 and the chem-kNN promotion gate do NOT apply.

How we tested this

Data: the canonical fitness matrix data/derived/canonical/v0/fitness_experiment_long.parquet (gene x condition fitness fit, with expName, gene_key=orgId:locusId, and a condition_key built from media/temperature). Replicates are multiple expName rows sharing a condition_key. Ran on 3 organisms: Keio, Caulo, MR1. No model training and no GPU — a lightweight residual-mining pass reusing existing loaders and the harness chem-kNN.

Two code versions were built (src/experiments/rdark/spike.py v1, then spike_repro.py v2), both uncommitted. v1 was found flawed: its naive top "surprises" were single-measurement (n_rep=1) artifacts (the low-replication/σ risk that had been predicted), and its gene-permutation null tested predictability rather than surprise-beyond-noise. v2 is the honest test and is the source of the reported numbers.

The v2 procedure per organism: (1) restrict to REPLICATED cells only (n_rep>=2). Keio had 204,606 replicated cells (35,748 orphan/dark), Caulo 284,832 (63,984 orphan), MR1 166,408 (65,296 orphan). (2) Compute chem-kNN expected fitness with chemistry_knn_predict(k=5, exclude_self=True) — exclude_self gives genuine leave-one-condition-out so the expectation never includes the scored cell; the inline kNN was verified against the canonical harness to ~1e-16. (3) Form the studentized residual r* = (observed - expected)/σ(condition). (4) Require the deviation to REPRODUCE across a gene's two replicate halves: both halves |z|>3 vs σ(condition) AND concordant sign; a passing cell is a CONFIRMED surprise. (5) Split cells by annotation via a Gene-table join on (orgId, locusId): dark/orphan = protein-coding (type=1) with desc null/empty or matching hypothetical/DUF/uncharacterized/unknown-function; annotated = the rest.

Two tests were run. GATE (real vs noise): a within-condition replicate-shuffle null — shuffle replicate labels within each condition, recompute residuals, count confirmed surprises surviving by chance; compare the real confirmed-orphan count to the shuffle-null count with an empirical p over 500 permutations (0.0020 is the 500-perm floor). ENRICHMENT (dark MORE surprising than annotated?): compare per-gene confirmed-surprise RATE for orphan vs annotated genes with a label-permutation p (label_p ~1.0 = orphans significantly QUIETER, i.e. the opposite of enriched). The planned Step 4 cross-organism ortholog concordance (Ortholog table, the intended primary non-circular validator) was NOT run — the spike stopped at Steps 1-3 once the enrichment premise failed.

Hypothesis / reasoning

The project's recurring wall — a non-parametric chem-kNN (which retrieves a gene's own fitness at chemically-near conditions) beats every global parametric model, adding organisms hurts, and naive model+kNN fusion fails — was suspected to be either a modeling failure or a data leak ('this feels like cheating'). What we've learned

The durable findings — what would survive even if we deleted all the code. Each has its supporting evidence and how we know it.

These are accurate measurements. Their interpretation was re-scoped on 2026-07-06: the "chem-kNN beats every model" finding is now understood as a property of a rigged benchmark (H1), not a deep verdict on modeling — see First-principles reframe.

1 · Conditional essentiality is a real but modest, noisy signal — the achievable ceiling is low ledger

There is genuine within-gene conditional signal (which conditions stress a given gene), but it is intrinsically noisy: the best any model could possibly do is bounded by how well two biological replicates of the same experiment agree. That replicate-agreement ceiling is only NDCG@5 ~0.66 and within-gene Spearman ~0.39 on the within-organism task. This is an oracle/upper bound, not a target a model should be expected to approach — it reframes every downstream number: a method is doing well relative to ~0.66, not relative to 1.0.

Evidence Replicate noise floor (R-LOCK-4 oracle, retrieval_noise_floor over 23 orgs with adequate replicate design): NDCG@5 ~0.66 and Spearman ~0.39 — NDCG@5 runs 0-to-1 (1 = perfect top-of-list ranking), Spearman -1-to-+1 (0 = random). The oracle uses replicate A's fit as the prediction and replicate B's fit as ground truth, so it captures the irreducible biological noise floor. For contrast, the strong chem-kNN baseline reaches NDCG@5 0.485, i.e. roughly 73% of the way to a repeat experiment.
How we know R-LOCK-4 defines a replicate oracle in harness.py that scores replicate-A-predicts-replicate-B; reported only for the 23 orgs with adequate replicate design so it is a fair per-org ceiling. Because it is measured the same way (NDCG@5/Spearman on the same eligible genes) as the models, it is directly comparable and establishes the scale.

2 · The signal is gene-idiosyncratic and local — the population/cross-gene pattern carries ~0 within-gene signal ledger

Almost all of the usable conditional signal lives in each gene's own deviations from the bulk, not in any cross-gene population pattern. The 'population condition profile' (which conditions hurt most genes, gene-identity removed) is essentially useless for ranking an individual gene's conditions. This is why a global model that minimizes average error over ~54k genes captures the bulk and averages the idiosyncratic per-gene deviations away — they look like cross-gene noise to it — while a per-gene lookup preserves them.

Evidence chem-NULL (gene-blind population profile: predict every gene's fit at a cold condition as the train-gene MEAN at the chemically-nearest train condition) scores within-gene Spearman ~0.02 and NDCG@5 ~0.31-0.34 (0.3434 on the 23-org/3-seed headline) — near-random ranking despite being derived from real population structure. Any gene-aware method beats it: the deep model reaches NDCG@5 0.4319 and chem-kNN 0.4852.
How we know chem-NULL is one of the three matched baselines scored on the identical eligible val gene set (denominator parity). Its ~0 within-gene Spearman directly demonstrates the population/cross-gene channel carries no within-gene ordering information, isolating the signal to per-gene deviations. Reinforced by the global-vs-local mechanism in synthesis section 4.

3 · Cross-organism transfer of the conditional signal is ~0 — frozen protein embeddings carry no transferable cross-genome conditional response ledger

When entire genomes are held out (leave-genomes-out), the model's within-gene ordering of conditions is statistically indistinguishable from random. This is the pivotal negative that reframed the whole project from cross-organism to within-organism and from RMSE to per-gene ranking. Two causes: held-out organisms' genes sit far from any training gene in embedding space (no anchor), and the embedding is fitness-blind (it encodes sequence/structure/proteome-context, not stress response).

Evidence Cross-organism holdout (T-regime, multi_org_balanced split): within-gene Spearman ~0.045 vs a ~0.43 replicate noise floor — ~0.045 is near-random (0), ~10x below the ~0.43 ceiling. This co-existed with 'fine' pointwise error (RMSE ~0.50, MAE ~0.28), the exact trap RMSE hides. Homology cause quantified at 1.6 sigma (S1, H-HOMO-01: held-out-org genes far from train genes), corroborated by homology-bin RMSE rising ~0.40 (cosine<0.5) to ~0.55 (cosine>0.85). Fitness-blindness: ProteomeLM beat raw ESM-C by only RMSE ~0.006 (T5-C), so the proteome-contextual machinery added almost no conditional signal.
How we know T1-T6 swept encoders/architectures/losses on a leave-genomes-out split (guardrails confirmed no split overlap); every arm sat at RMSE ~0.50 yet within-gene Spearman stayed ~0.045. The homology-bin RMSE breakdown and the ESM-C swap isolate the two causes. RMSE looking healthy while ranking is random is the durable lesson that low error can hide a useless model on a gene-mean-dominated target.

4 · On the warm within-organism task, a chemistry-similarity kNN is a strong baseline that no learned global model beats ledger

chem-kNN — predict a gene's fit at a cold (unseen) condition from that same gene's own fit at its chemically-nearest train conditions — is the competitive gate, and every learned global model tested falls below it. This holds across encoders (fingerprint variants), objectives (pointwise and ranking losses), and capacities (linear bilinear MF up to a 2.5M-param deep model), and across both frozen sequence embeddings and learned fitness-aware gene representations. The deep model does clear the gene-blind floor, so it captures gene-specific structure — it just cannot beat local lookup.

Evidence 23-org/3-seed headline NDCG@5: chem-kNN gate 0.4852; best deep model (pointwise_huber) 0.4319 (gap ~-0.053); linear inductive-MF 0.4290; chem-NULL floor 0.3434. Promotion requires beating chem-kNN by >=~0.026 NDCG@5 with disjoint org->gene hierarchical bootstrap CIs — the model is BELOW the gate, not above it. Sweeps: R1 encoder (6 arms x 3 seeds), R-LOSS (MSE/Huber/RankNet/LambdaRank/ListMLE/ApproxNDCG, Huber best at 0.435), capacity (13k-param MF ~ 2.5M-param deep). All scored on identical eligible val genes (N=39,356 headline).
How we know The locked harness enforces denominator parity (model and all baselines on the same eligible genes) and a strict disjoint-CI promotion gate. Independent sweeps of encoder, objective, and capacity all plateau at NDCG@5 ~0.42-0.44 below the 0.485 gate, and R-HYBRID (three learned fusions) converged on ~0 improvement — strong evidence the ceiling is real, not a single-design artifact.

5 · The warm task is memorization-dominated — local lookup wins because the bottleneck is structural, not the embedding ledger

The useful deliverable ('rank a known gene's stressors in a known organism') is achievable at NDCG@5 ~0.485, but via memorization/lookup, not learning: reading each gene's own history and interpolating by chemistry similarity. Deep learning as configured adds nothing over it. Crucially the bottleneck is global-vs-local structure, not the embedding's fitness-blindness: a learned fitness-aware gene latent (linear-MF) does no better than the frozen sequence embedding, because the warm task is fundamentally about memorizing each gene's own history, which any GLOBAL representation compresses away.

Evidence Frozen sequence embedding (deep model) NDCG@5 ~0.42 vs learned fitness-aware latent (linear-MF) ~0.43 — swapping a fitness-blind rep for a fitness-aware one did NOT close the gap to kNN's 0.485; both lose. R-HYBRID confirmed: static z-ensemble gave only +0.008 over kNN (below the 0.026 gate), and three learned fusions (residual +0.0002, retrieval-augmented -0.0059, learned gating -0.0081) converged on ~0; learned gating settled at mean alpha ~0.46 but every unit of weight on the model HURT ('trust the lookup').
How we know linear-MF is itself a fitness-aware-embedding experiment (free per-gene latents learned entirely from fitness data), so its failure to beat kNN isolates the bottleneck as global-vs-local rather than representation. R-HYBRID then showed even optimally combining global model + lookup extracts no promotable signal, and the learned gate's own weights point at the lookup. Together these say the warm task is memorization-dominated.

6 · The negative is noise-robust — cleaner labels do not let the model overtake lookup ledger

The model-loses-to-kNN result is not an artifact of measurement noise. Stratifying eligible val genes by measurement confidence (Wetmore moderated t-statistic, abs_t), chem-kNN beats the deep model in every confidence quartile and at every per-cell |t| threshold — the model never overtakes lookup even on the cleanest-measured genes. Label noise does depress all measured performance and accounts for part of the model's deficit, but never enough to close it, and confidence-weighted training does not help.

Evidence R-CONF-DEC-001: chem-kNN > deep model in all 4 confidence quartiles and at every |t| threshold. Every method AND the replicate ceiling rise monotonically with confidence (ceiling 0.59 -> 0.83 from low to high confidence), confirming noise depresses measured numbers. The model-vs-ceiling gap narrows only 0.055 -> 0.040 across strata — narrowing but never closing. Confidence-weighted training changed NDCG@5 by ~-0.004 (no help).
How we know abs_t (moderated t) is a per-cell measurement-confidence proxy; stratifying by it and re-scoring shows kNN's lead survives at high confidence, so the deficit is not label-noise-driven. The monotone rise of the ceiling with confidence proves noise is present and real, and the residual (structural, local-vs-global) gap that persists at high confidence proves cleaner labels would not fix the model.

7 · The frozen embedding DOES carry transferable conditional signal — cold-gene generalization is a first positive ledger

The warm-split negative is a memorization gap, NOT an 'embeddings carry no signal' result. On the cold-gene split (unseen genes within known organisms), where chem-kNN vanishes because a gene has no own-history to look up, the global model (frozen embedding + chemistry) beats the only applicable baseline. This works because cross-GENE-within-organism transfer (place an unseen gene among the organism's seen genes, reuse the shared per-organism chemistry->fitness structure) is a much easier ask than the cross-ORGANISM transfer that failed at ~0.045.

Evidence Cold-gene, 23-org/3-seed, n=11,761 eligible cold val genes: chem-kNN/linear-MF coverage 0% (inapplicable — no own-gene history); chem-NULL gate NDCG@5 0.2447 / Spearman 0.0359; model NDCG@5 0.2748 / Spearman 0.0735; delta +0.0301 NDCG@5 / +0.0376 Spearman. Per-seed model NDCG@5 [0.2732, 0.2746, 0.2765] all disjoint above the constant 0.2447 gate; fast 3-org set reproduces the sign (+0.0271). HONESTY: on the primary metric the hierarchical CIs OVERLAP (model 0.2748 [0.2424,0.3179] vs gate 0.2447 [0.2118,0.2823]); only secondary Spearman is CI-disjoint. It is a directionally robust point-estimate win, not a strict disjoint-CI promotion, and against a weaker gate (chem-NULL) so it changes no headline number.
How we know R-COLD-DEC-001 ran the diagnostic: chem-kNN's 0% coverage forces chem-NULL as the gate, and the model beats it consistently across all 3 seeds and reproduces on the fast set. The regime distinction (cross-gene-within-org vs cross-org) explains why the discouraging T-stage prior did not transfer. The overlapping primary-metric CI is reported honestly — it corrected an earlier Spearman-only 'CI-confirmed' read, which is why NDCG@5 is held primary.

8 · Cofit leakage tripwire — never use feba.db's precomputed Cofit as a gene-gene edge on held-out splits ledger

feba.db ships a precomputed Cofit table (Pearson correlation between gene fitness profiles computed over ALL experiments, split-blind). Using it on any condition-holdout or cold-gene method is target leakage: the correlation spans the held-out val conditions, so a gene's top co-fitness neighbor's train profile reconstructs that gene's own held-out answer key. The rule: never read feba.db Cofit (or any all-experiment co-fitness matrix) into a cold-gene or condition-holdout method; co-fitness must be recomputed train-only, and on the cold-gene split a train-only co-fitness edge is undefined, so the frozen embedding is the only leakage-free gene-gene edge source there.

Evidence Smoking gun (round-2 evolutionary-search verification, Keio/Caulo/MR1): cofit-only NDCG@5 ~0.73-0.75, which EXCEEDS even the warm chem-kNN gate (~0.485) and approaches the replicate ceiling (~0.66) — physically impossible without a leak. Mechanism confirmed: the rank-1 cofit-neighbor's train profile correlates with the val gene's TRUE held-out profile at median r ~0.56 (63% of genes > 0.5). Inverted ablation confirms it: cofit-only outscores any fusion that includes it.
How we know An impossibly-high NDCG@5 above the warm gate was the tripwire; the direct correlation between the neighbor's train profile and the val gene's held-out truth (median r ~0.56) is the mechanistic proof of the leak, and the inverted ablation (adding cofit only ever helps, never hurts, and cofit-alone beats everything) confirms it is answer-key contamination rather than signal. This is why honest gene-axis methods (GENE-NW) reduce to the R-COLD embedding signal instead of adding new information.

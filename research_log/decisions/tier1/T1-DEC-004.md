### Assumption Under Test

- assumption_statement: Including unit-mixed concentration values on the ~2%
  of chemistry cells with recorded `amount` provides measurable RMSE+MAE
  improvement over pure binary presence/absence encoding.
- assumption_type: representation
- why_it_matters: T1-DEC-003 locked `log1p` as the chemistry transform but
  never tested binary vs log1p directly. Per `feature_contract.yaml`,
  concentration values are pooled without unit conversion — so feeding them
  to the model is at best representation-questionable, at worst a unit
  confound. T1-B.3 closes the gap with a controlled comparison.

### Pre-Registered Test Plan

- comparison: 2 arms × 3 seeds.
  - **binary**: every present chemistry cell = 1.0 (identical to T1-A
    multihot)
  - **log1p**: presence = 1.0 for NaN amount, `log1p(amount)` for cells with
    recorded concentration (T1-B locked default)
- fixed_controls (identical to T1-A, T1-B):
  - split_protocol_id: `multi_org_balanced`
  - feature_contract_id: `de21504134c84a6c`
  - quality_policy_id: `weighted_full` + full org pool
  - condition_encoder: `multihot_canonical_id` (T1-DEC-002 winner)
  - seeds: {0, 1, 2}, epochs: 8
  - model: shallow concat-linear MLP, hidden=256, dropout=0.1
  - lr=1e-3, weight_decay=1e-4, batch_size=8192
- metrics_primary: [rmse, mae]
- promotion_rule:
  - Default: lock binary (conservative representation; mixed-unit concentrations
    are not honestly encodable).
  - Override: lock log1p only if it clearly beats binary by RMSE AND MAE
    thresholds in the same direction, AND bootstrap CIs are disjoint.

### Evidence Summary

#### Per-arm metrics (mean ± std, 3 seeds)

| Arm | RMSE | MAE |
|---|---:|---:|
| binary | 0.5150 ± 0.0020 | 0.2957 ± 0.0014 |
| log1p | 0.5159 ± 0.0021 | 0.2940 ± 0.0014 |

#### Gaps

| Metric | binary − log1p | Threshold (multi_org_balanced) | Above threshold? | Direction |
|---|---:|---:|---|---|
| RMSE | −0.0009 | 0.0212 | No | binary marginally better |
| MAE | +0.0017 | 0.005 | No (60% of threshold) | log1p better |

#### Bootstrap CIs (seed 0, 1000 row-resamples)

| Arm | RMSE 95% CI | MAE 95% CI |
|---|---|---|
| binary | [0.5113, 0.5149] | [0.2945, 0.2956] |
| log1p | [0.5118, 0.5155] | [0.2919, 0.2930] |

- RMSE: CIs overlap by ~0.003 → statistically tied.
- MAE: CIs are disjoint by ~0.0015 → **log1p statistically better on MAE**,
  but gap is sub-threshold.

#### The H-METRIC-01 disagreement (third occurrence in T1)

Different metrics favor different arms — RMSE marginally favors binary, MAE
statistically favors log1p. This is the regime S2-DEC-001 designed the
co-primary policy to handle: a winner requires both RMSE AND MAE gaps to
exceed threshold *in the same direction*. log1p does not qualify here
(RMSE gap is in the wrong direction, MAE gap is below threshold).

### Decision

- decision_outcome: **lock `binary` chemistry encoding.** Supersedes
  T1-DEC-003's `log1p` lock.
- rationale:
  1. **No clear winner per S2-locked rule.** RMSE/MAE disagree, neither gap
     exceeds threshold in the same direction.
  2. **Epistemic conservatism breaks the tie toward binary.** The locked
     `feature_contract.yaml::concentration_policy` says: "do NOT use raw
     concentrations for cross-experiment comparisons or magnitude claims
     until T1 normalizes units." Including unit-mixed concentrations
     without unit normalization isn't honestly describable as
     "concentration information" — it's numeric strings the workbook
     pooled with no unit context.
  3. **The empirical case is weak.** A 0.0017 MAE advantage on the central
     mass doesn't justify the representation complexity, the unit-mixing
     concern, or the eventual reviewer question of "what do these numbers
     mean physically?"
  4. **T1-A's substrate carries forward unchanged.** Binary multihot is
     exactly what T1-A used; it cleared the H-BASE-01 gate on
     multi_org_balanced and survived the largest_by_rows stress test
     (T1-DEC-002). No new diagnostic run needed.
- risks_remaining:
  1. **MAE advantage discarded.** log1p's 0.0017 MAE edge is real,
     statistically significant, just below the locked threshold. If a
     later tier finds that central-mass error reduction matters
     disproportionately, revisit. T1-B.3 data is reproducible from
     `artifacts/cache/t1b3/` and the arm-comparison code.
  2. **The decision is conditional on the unit-mixing concern.** If
     `units_1..units_4` are eventually parsed and concentrations are
     unit-normalized (REFACTORPLAN §12 deferred), H-ENC-02 deserves
     another look.
- next_action:
  - Lock binary chemistry encoding for all downstream T1+ runs.
  - Supersede T1-DEC-003 specifically on the encoding choice. T1-DEC-003's
    other findings (raw < log1p, raw < bounded) remain valid for any future
    runs that do include concentrations.
  - Proceed to **T1-C (unknown handling, H-ENC-03)** using the binary
    chemistry encoding.

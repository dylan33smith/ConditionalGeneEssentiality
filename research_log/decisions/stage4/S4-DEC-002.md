### Context

OPEN-001 established that `condition_1..4` are applied chemistry (stressors), not
metadata. S4-DEC-001 incorrectly encoded them as categorical metadata and used a
media-only multihot. This entry locks **Option D**: a train-only per-experiment
**long** chemistry table plus a **wide** metadata table, with stressor strings
resolved to workbook `Canonical_ID` where possible via
`data_contract/preprocessing/_review/stressor_to_canonical_id.yaml` (matcher report
`stressor_match_report.csv` + ratified map; Phase 0 script:
`scripts/build_stressor_match_report.py`).

### Pre-registered schema

**`experiment_chemistry.parquet`** (one row per `(experiment_id, canonical_id, role)`):
- `experiment_id`: SHA256-hex (64 chars) of `orgId`, `setName`, `seqindex`, `media_key`
  where **`media_key` is the empty string** when `media` is missing / NaN.
- `canonical_id`: **raw string** as resolved from workbook + stressor map (no S4
  prevalence rewrite in the parquet). `<UNK>` / `<UNK_STRESSOR>` are **reserved
  vocab indices** for T1 OOV handling, not row-level replacements in S4.
- `role`: `medium` | `stressor`
- `amount`: raw scalar (workbook `Amount` or `concentration_i`); NaN allowed
- `log1p_amount`: train-fitted log1p z-score (same scaler for medium + stressor amounts)

**`experiment_metadata.parquet`** (one row per experiment, aligned by `experiment_id`):
- Categoricals as `*_idx` from frozen vocabs (`<UNK>`=0, `<MISSING>`=1):
  - `oxygen` ← `aerobic`
  - `experiment_group` ← `expGroup`
  - `liquid_state` ← `liquid`
- **Excluded:** `mutantLibrary` / genotype — not emitted (organism-holdout; not used as a
  condition channel in the locked contract).
- Numerics as `*_z` + `*_is_finite` (train z-score, NaN → 0 in z with is_finite flag):
  - `temperature_c` ← `temperature` (string-parsed)
  - `pH` ← `pH`
  - `shaking_rpm` ← `shaking` (regex `(\d+) rpm`)

**Prevalence:** **Chemistry** vocab listing uses **distinct train experiments** per
`canonical_id` with `chemistry_prevalence_threshold: 0.0` (no canonical dropped from the
vocab for rarity). **Metadata** vocabs still use `metadata_prevalence_threshold: 0.001`.

**`<UNK_STRESSOR>`:** reserved slot for T1 stressor OOV / policy buckets (see OPEN-001).
